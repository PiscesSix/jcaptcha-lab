Bấm vào dòng để xem request/response. Cookie JSESSIONID là HttpOnly nên JavaScript không đọc được — trình duyệt tự gửi kèm.

    


    

      
Luồng hoạt động

      
    
        
  1. Bấm ↻ → makeImageCap() gọi GET …/simplecaptchanew (axios trên web gốc, fetch ở đây).
    2. 
        
  2. Server lấy session từ cookie JSESSIONID (chưa có thì tạo mới + Set-Cookie), sinh ảnh, lưu đáp án vào session.
    3. 
        
  3. Server trả PNG với Content-Disposition: attachment; filename="<millis>.png" — không kèm id, không kèm đáp án.
    4. 
        
  4. Trình duyệt biến dữ liệu ảnh thành blob: URL (URL.createObjectURL) — cái UUID trong link là của trình duyệt, server không biết.
    5. 
        
  5. Người dùng gõ mã → form gửi POST …/dossiers/{id}/actions dạng multipart, có field j_captcha_response; trình duyệt tự kèm cookie.
    6. 
        
  6. Server tìm session theo cookie, so j_captcha_response với đáp án đã lưu, xóa đáp án, đúng thì mới xử lý action.
